# cco 全量落地总计划：简单主路径 · 多 CLI 并行 · 安全 · 无证书发布

## 目标
在**不改 Mode B `confirm_start`、不新建 Scheduler** 的前提下，把多轮诉求收成一条**上手简单、界面不杂、流程短**的产品：

```text
选项目 → 聊天共建（可附图）→ 问后是否落盘 .md
     → 计划管理（默认藏 · 开文件夹才显列表）
     → 单击选中 / 双击编辑 / 分配
     → 拆分时可任命多 CLI（Claude ‖ Codex 同 run 并行）
     → 确认屏可改引擎 → 跑（worktree + handoff + inspect）
```

**设计硬约束**
1. 上手：新用户 3 步内能写出并分配第一个计划  
2. 清晰：默认只显示该看的；计划栏默认关  
3. 不杂：顶栏 ≤3 主按钮；无多句常驻确认堆叠  
4. 流程短：保存问一次、分配点一次；唯一执行入口  
5. 全量：UX + 多 CLI 产品化 + 运行时安全 + 无证书发布保护**都要做**，按波次落地  

## 一句话现状（避免重做）

| 簇 | 已落地（勿当零起点） | 真缺口（本计划要做） |
|----|----------------------|----------------------|
| 编排内核 M0–M4 / D0–D4 | ✅ | — |
| Mode B / P-loop / inspect 主闭环 | ✅ | 多 CLI 分配体验残差 |
| 多 CLI runtime | P0–P1 + P2-1/P2-3 大半 ✅ | **P2-2/4/5/6**：路由、拆分任命、确认屏改引擎、host diff |
| 聊天 C0–C2 · H0–H4 · 计划管理 G0–G6 | 主线多已接（附图/2 天/落盘/右轨） | **体感收口**：噪声、默认藏栏、单击/双击、落盘再问、文档勾选与目视 |
| 运行时路径/XSS 护栏 | 部分有 | **统一护栏 + 呈现审计** |
| 发布保护 | 明文双 web、无 strip 策略 | **无证书** strip·minify·去双份明文·可选资源混淆 |

**多 CLI 关键结论（再强调）**  
「能并行」已在 Scheduler 总线；你觉得「没实现」= **拆分不混部 + 桌面看不见/改不了引擎 + 无 L1 路由**。本计划补产品化，**不重写调度器**。

## 修后唯一心智（用户侧）

```text
① 侧栏选项目（无跑 → 聊天；有跑 → 执行）
② 文字 + 可选图 → AI 草稿（不自动写盘）
③ 「是否保存为 .md？」→ 是 → 写入「计划文件夹」
④ 「计划管理」展开右栏（默认关）· 列表来自该文件夹
⑤ 单击=选中 · 双击=编辑 · 分配（列表/弹窗同源方案 A）
⑥ 分配 → 拆分（任务带 provider/role/scope）→ 确认屏可改引擎
⑦ 确认 → 同波 Claude‖Codex 并行（worktree）→ handoff → inspect
⑧ 聊天 >2 天自动清；计划 md 不删
```

## 范围

### 纳入（全量，分波）

#### 波次 0 — 基线冻结与对账（0.5～1 天）
- 对照代码勾选：G/H/U 哪些已真绿、哪些只文档绿  
- 冻结本总计划阶段 ID：**W0–W5**（总账挂 **D5 / P-master**；**禁止**回灌 D0–D4）  
- 入口表：path 写盘 / spawn cwd / list plan / chat 附件  

#### 波次 1 — 聊天与计划管理收口（产品主痛，优先可感）
> 在 G0–G6 / H0–H4 之上做**体感与缺口**，不重做已有 IPC。

1. **右栏默认隐藏**；顶栏主按钮 **「计划管理」**（展开/收起）；跑中另显「返回执行」  
2. **打开计划文件夹**（须 ∈ 项目根；默认建议 `plans/`）→ 才显示列表；per-project 记住 `plan_folder_rel`  
3. **后续 md 均写入该文件夹**（`chat-YYYYMMDD-HHMM.md` 等）  
4. **单击选中 / 双击编辑**（单击不再只读弹全文；可选「预览」）；列表+编辑器/弹窗均有 **分配**  
5. **每次新草稿问是否落盘**（不自动写盘；否=会话预览）  
6. **去常驻噪声**：页头长步骤仅空会话；输入下不堆就绪/确认长句；环境故障一条可关；后台最多一条 ghost banner  
7. **附图**（若已接则目视补齐）：jpg/png/webp/gif · 大小/张数上限 · `.cco/chat/attachments/`  
8. **聊天 2 天清理**（若已接则验收）：清会话/附件；**不删**计划 md  
9. 空态三句说清下一步；未保存/未选中不可分配  

#### 波次 2 — 多 CLI 并行产品化（本轮你最关心的「没实现」）
> Runtime 已有；本波 = **任命 + 可见 + 可改 + 合法校验**。

1. **P2-4 路由 L1**  
   - 任务 `tags` + 配置表 `routing`（例：`frontend→claude`、`backend→codex`、`inspect→claude`）  
   - 无 tag 时用 `default_provider`；**不**静默随机  

2. **P2-5 拆分带任命**  
   - Mode B planner / 启发式：输出 per-task `provider` + 建议 `role`/`scope`/`outputs`  
   - 聊天落盘后结构化路径：进入分配时**尽量保真**已有 provider，禁止 `apply_worker_defaults` **无脑全刷成一家**（除非用户选「强制统一引擎」）  
   - 混写并行计划：默认 `worktree=true`；缺 scope 的 implement 给出可编辑默认路径  

3. **P2-6 确认屏**  
   - 任务表列：**引擎**下拉（claude/codex/fake）  
   - 只读展示 role/scope 摘要；非法（混跑无 worktree、scope 相交）红字挡「开始」  
   - 轻量 Board：handoff 总览入口（链到 run 后状态即可，不重做 TUI）  

4. **P2-2 host diff（inspect 输入）**  
   - 任务结束后预生成变更列表片段，供 inspect 波消费  

5. **Doctor / 设置**  
   - 分家就绪：claude / codex 各自「已装/未装/版本」  
   - `max_parallel` 与每家上限可见、可改（默认不吓人）  
   - 说明：同 run 混部 = 模式 A；**不**鼓励同项目双 run 互撞  

6. **示例 + 测**  
   - 保留/更新 `mixed-claude-codex` 示例  
   - `mixed_provider_smoke` + 新增：确认屏改引擎不丢、路由表命中、强制统一开关  

7. **并行安全默认（产品文案写死）**  
```text
Wave0 scout(claude) → Wave1 implement 并行 claude‖codex
→ Wave2 integrate(一家) → Wave3 inspect(一家)+host acceptance
```

#### 波次 3 — 运行时安全
1. `require_allowed_project` + `resolve_under_root`（canonicalize；拒 `..`/绝对逃逸）  
2. 接线：chat_*、list/preview/save plan、start run/job、logs、terminal、附件路径  
3. 标识符净化：run_id/session_id/计划相对路径  
4. 前端：消息/日志/计划预览 **不**当裸 HTML；`textContent`/转义  
5. 可选 `security_profile=normal|strict`（默认 normal 不破主路径）  
6. 不扩大 Tauri 任意 fs/shell；单测逃逸正反例  

#### 波次 4 — 无证书发布保护
1. release：`lto` · `strip` · 统一 profile / `package-app.sh`  
2. 前端 minify/bundle → `web-dist/`，**只打包 dist**  
3. **去掉**双份明文 `web/` 拷贝（或仅 debug）  
4. 「加壳」= strip + 去符号 + 资源不落源码 + 可选启动资源哈希；**默认无 UPX**；**无 codesign/公证**（无证书）  
5. 加密：P0=C1（embed minify）；P1 可选 AES 资源包；密钥若落盘走 Keychain；**不**加密用户计划 md  
6. 文档声明：提高门槛非绝对防逆向；zip 标「未签名内测」  

#### 波次 5 — 联调 · 文档 · 总账
- 端到端目视清单（见验收）  
- `node --check` 相关 js · `cargo test --lib` · 关键 smoke  
- 回写子计划勾选（multi-cli P2-x、UX 残差）；总账 **P-master / D5** 指针；**不**回灌 D0–D4  
- 过时「multi-cli 未实施」文案改为「P0–P1 已落 · P2 产品化本计划」  

### 不纳入（边界）
- 第二套 Scheduler / 进程内双嵌 SDK  
- 模式 C 竞赛双写、同项目多 run 大力推广  
- C3：流式多会话、聊天内直接开跑、diff 编辑器全家桶  
- Developer ID / 公证 / App Store / 默认 UPX  
- 完整 OS 沙箱、多用户 RBAC、加密用户仓库  
- 改 `confirm_start` 唯一业务入口语义

```text
┌─ 共建计划 · [计划管理] ·（跑中：[返回执行]）─┐
│ 消息流（干净）                                │
│ [可选一条环境故障]                            │

└──────────────────────────────────────────────┘
  右栏关闭
```

### 计划管理开
```text
左聊天 | 右：文件夹 plans/ [更换]
       | · 标题A  [未执行]  ←选中
       | · 标题B  [已执行]
       | [分配计划]（选中后）
单击选中 · 双击编辑 · 预览可选
```

### 确认屏（多 CLI）
```text
任务表：id | 标题 | 引擎▾ | role | scope 摘要
底部：worktree ✓ · 并行 n · [开始执行]
非法：红字禁用开始
```

## 验收

### 主路径上手
- [ ] 新用户：选项目 → 聊天出草稿 → 确认保存 md → 计划管理见列表 → 选中 → 分配 → 确认 → 跑，**无需读文档**  
- [ ] 右栏默认不显示；打开计划文件夹后才有列表；新 md 在该夹下  
- [ ] 单击选中、双击编辑；列表与弹窗/编辑器均可分配  
- [ ] 每次新草稿都询问是否生成 md；拒绝则不写盘  
- [ ] 输入下无多句常驻确认/步骤堆叠  
- [ ] 附图可发（上限内）；>2 天聊天自动清，计划 md 仍在  

### 多 CLI 并行
- [ ] 手写/拆分后的计划可同 run 出现 claude 与 codex 的 `task_start`（events）  
- [ ] 确认屏可改单任务引擎且**不会**被默认 provider 全量抹平（除非强制统一）  
- [ ] 混写并行无 worktree / scope 相交 → validate 或确认屏拦截  
- [ ] doctor 能分家显示两家 CLI 就绪  
- [ ] routing/tags 或 planner 至少一种路径能自动给出不同 provider  
- [ ] inspect 可消费 host diff（P2-2）；VERDICT FAIL 仍 pause（已有）  
- [ ] `cargo test` 含 mixed_provider 及相关新测通过  

### 安全与发布
- [ ] 项目外 path / `..` 逃逸：写盘与列计划拒绝  
- [ ] 假日志/聊天气泡含 `<script>` 不执行  
- [ ] 发布产物：strip；无完整明文 `web/js` 源双拷；无证书脚本不失败硬挡  
- [ ] 主路径 normal 行为与现网一致  

### 文档
- [ ] multi-cli §6 P2-2/4/5/6 勾选更新  
- [ ] 本计划 W0–W5 勾选；总账 D5 **P-master** 指针；不回灌 D0–D4  

## 约束
- 工作区仅本仓库；优先改 `web/` · `src/services/*` · `src/plan/planner/*` · `src/runtime/*` · `scripts/` · 相关 docs  
- 计划产物用户侧仍是 **md 散文**；结构化 PlanIR 仅在分配/拆分后  
- fake 不伪装可静默真交付  
- 无证书：不把 codesign 做成硬失败  

## 风险

| 风险 | 缓解 |
|------|------|
| 文档写「已落地」与体感不符 | W0 对账表为准，半绿进 W1 |
| Mode B 全刷 provider 毁混部 | W2 显式保真 + 强制统一开关 |
| 双 CLI 未装导致「并跑失败」 | doctor 分家提示；允许单家降级 |
| W1/W2 抢同一前端文件 | 先 W1 合入再 W2 确认屏；或分 PR |
| 加壳/加密期望值过高 | 文档写清威胁模型；默认 C1 |
| 范围过大一次做不完 | **按 W1→W2→W3→W4 切片合并**；每波可独立验收 |
