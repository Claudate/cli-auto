上手（模式 B）

          
    
            
  1. 点侧栏 ＋ 添加本机项目文件夹
    2. 
            
  2. 选择一份计划文档（.md 即可，不必手写任务表）
    3. 
            
  3. 点分配计划 — AI 自动拆分任务并开始执行
    4. 
            
  4. 每个任务一个 CLI 窗口，可拖动位置、可关闭；需要时再展开日志
    5. 
            
  5. 监视页：排队 / 运行中 / 已完成 的 CLI 都能点开看日志
    6. 
          

          
计划是什么？

          
计划 = 给 AI 的任务说明书。优先用 .md；已有结构化任务表也可用「解析已有结构」跳过启发式拆分。

          
常见操作

          
    
            
  • 重新规划：回到选计划，改高级选项后再拆一次
    • 
            
  • 全部停止：结束当前运行中的全部任务
    • 
            
  • 继续未完成任务：在暂停/失败后尝试 resume
    • 
            
  • 高级选项：规划方式（AI / 解析 / 模拟拆分）、运行引擎、执行方式
    • 
            
  • 环境检查：确认本机 Claude CLI 与密钥是否就绪
    • 
          

          
Claude 路径示例

          
[providers.claude]
bin = "/Users/你/.local/bin/claude"
