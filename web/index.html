            三步上手

            1. 点侧栏 添加 本机工作文件夹
            2. 在聊天里说清目标（或点欢迎页模板），生成计划
            3. 点拆成步骤 → 看清波次 → 点执行规划

            默认会停在拆分台，不会自动开跑。可选步骤需你勾选才会执行。拆分台默认用智能拆分；来源会在拆分台标明。欢迎页可跳过选择「我更常拿 cco 干什么」，也可在设置里改。点左侧步骤看完整说明；可编辑后再执行规划。

            计划是什么？

            计划 = 用大白话写的「要干什么」。优先 .md 文档；也可先聊天共建，再拆成步骤并行推进。

            常见操作

            • 重新规划：保留你在拆分台上的修改，再拆一次
            • 执行规划：核对后开跑（唯一业务开跑）
            • 全部停止：结束当前运行中的全部任务
            • 继续未完成任务：暂停/失败后尝试接着做
            • 侧栏项目 ×：从 cco 列表移除（不删电脑文件夹）
            • 设置 · 环境检查：通道、并发、本机环境（进阶）
            给进阶用户

            本机 CLI 路径、TOML 配置、拆分台借鉴清单等。

            CLI 路径示例

            [providers.claude]
bin = "/Users/你/.local/bin/claude"

            拆分台借鉴清单

            • 执行规划 — 唯一业务开跑（人闸 · confirm_start）
            • 步骤标题像待办；卡片「等：… / 可马上开始」；右栏默认「要做什么 · 怎样算做完」
            • 计划文件真源 plans/*.md；高级可写回步骤摘要
            • 人改优先 — 重新规划会尽量保留你的修改
