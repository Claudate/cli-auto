# 仓库 Markdown 清理、整理与合并

## 目标

在**不改业务代码、不破坏** CLAUDE 导航树 / 契约 / 示例夹具的前提下，把仓库文档收成可维护的三档结构：

1. **删**误放、无索引的垃圾  
2. **迁**主线已 ✅、日常不再勾选的落地全文 → `docs/archive/`  
3. **合**同主题多份 ✅ 文档的「改行为仍要读」要点 → 少量短真源（无新阶段勾选表）  
4. **留**仍有 ☐ 的活跃计划与不可替代的产品/架构真源  
5. **刷** L1、`docs/CLAUDE.md`、`docs/archive/README.md` 索引，无死链  

**成功体感**：打开 `docs/` 一眼分清「真源 / 还在做 / 历史」；拆分主题不再七份并列勾选感；从 L1 点到任意索引文件可达。

## 非目标

- 不改 Rust / web 行为，不做功能迭代  
- 不删 `**/CLAUDE.md`、`docs/contracts/**`、`examples/**`、`tests/fixtures/**`、`.claude/skills/**`  
- 不删 `PRODUCT.md`；`README.md` 只修死链与过时指针  
- 禁止平行第二套阶段表，禁止把已 ✅ 再写成缺口  
- 不整篇重写 `architecture-redesign` / `gap` 正文  
- 不把 Guide 全量 / 人生 OS 当垃圾硬删（标后置即可）  
- 不把仍有 ☐ 的活跃计划合并进 archive  

## 约束与原则

| 做 | 不做 |
|----|------|
| 已闭环全文用 `git mv` 进 archive，保留 git 历史 | 静默 `rm` 已闭环全文 |
| 新建/改写摘要 **≤ ~150 行**，只写规则与 archive 指针 | 再造带 P0–P5 勾选的「总落地」 |
| 开项 ☐ 只写在**一处** | 多文档各写一半开项 |
| 索引一行 = 文件职责 | docs 根继续堆「诊断 + 落地 + 金样」同主题 |

## 任务大纲

1. **盘点冻结（只读）**  
   - 列出 `docs/*.md` 与根目录相关 `.md` 的三档归属表（删 / 归档 / 留 / 合并产物）。  
   - 全仓检索待迁/待删文件名，记下需改链位置（根 CLAUDE、docs/CLAUDE、archive/README、PRODUCT、README、web/CLAUDE 等）。  
   - 确认 B 表文件均存在且无「仍有 ☐ 开项却被整篇归档」的误伤。  
   - **产出**：冻结分档表 + 改链表。

2. **删除误放**  
   - 删除 `docs/one/` 整个目录。  
   - （可选）本机清空 `.cco-out/**/*.md`，不提交。  
   - **产出**：无孤立 `docs/one/`。

3. **抽取开项后归档 soft-sqlite 与其它 B 表全文**  
   - 从 `split-soft-sqlite-2026-07-21.md` 抽出仍开的 **S2–S6** 为表（只保留一处目标落点：见任务 4）。  
   - 对 B 表全部文件执行 `git mv` → `docs/archive/`（含根 `claude-cli-orchestrator-plan.md`、`subjective-desire-decision-concept.md`）。  
   - **产出**：docs 根无 B 表文件名；archive 内文件名与迁前一致。

4. **C1 拆分主题合并**  
   - 新建 `docs/split-product-rules.md`（≤150 行，无阶段勾选）：产品规则 + archive 指针。

   - **产出**：拆分「改行为读 2 份」；S2–S6 不双份。

5. **C2 / C3 / C4 轻整理**  
   - `product-mainpath-optimize-2026-07-20.md` 文首加「仍有效产品规则」5～10 条（来自已归档 ux/shell）。  
   - 子集落地文、guided 文：改概念/pilotdeck 链到 `archive/…`；guided 文首标后置状态。  
   - C4 四份业务规则文首统一「状态：规则有效 · 阶段勾选勿继承」。  
   - **产出**：无死链到旧路径；活跃 ☐ 仍只在子集/guided。

6. **索引刷新**  
   - 更新 `docs/archive/README.md`（新归档逐行）。  
   - 更新 `docs/CLAUDE.md`、根 `CLAUDE.md`、`README.md` 及其它改链表命中处。  
   - **产出**：L1 → docs → archive 导航闭环；检索旧路径仅剩「已迁说明」或零业务引用。

7. **收口自检**  
   - `docs/` 根文件列表对照冻结表。  
   - 抽查：split 规则、存储文、C4 文首、子集/guided 链接。
