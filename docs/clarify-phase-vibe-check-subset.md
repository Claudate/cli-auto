## 0. 一句话

**澄清相** = 聊天写计划前的轻量子集：选入口 → 答几题（或跳过）→ Brief → 认领成 plan → 再「分配计划」。  
它只加厚 PRODUCT 五步的 **① 生成计划**；②–⑤（核对 · 拆分 · 并行 · 巡检）不变。  
**认领 ≠ 开跑**；唯一业务开跑仍是拆分台确认（`split::confirm` / 分配后确认）。

## 1. 做（本子集）

| 能力 | 说明 |
|------|------|
| **三入口** | 想清楚再说 · 从想法到计划（默认）· 已想清直接写计划 |
| **五必需槽** | 目标对象 · 痛苦时刻 · 可观察结果 · 明确不做 · 怎样算做完 |
| **追问** | ≤5 题；编号 + A/B/C；「你定 / 直接出计划」可跳过并**写假设** |
| **Brief** | 一页可扫：问题 · 给谁 · 做/不做 · 得/失 · 证据轻标签 · 未决 · 验收 · V1 |
| **认领 → plan** | 主 CTA「认领并写成计划」→ 只写草稿 / plan fence |
| **空心提醒（不拦）** | 缺验收 / 非目标时黄条；**不** disable 保存与分配（对齐 D0） |

### 1.1 三入口

| 入口 | 行为 |
|------|------|
| **想清楚再说** | 只产出 Brief；可不落 plan |
| **从想法到计划**（默认） | 澄清 → Brief → 认领 → plan |
| **已想清，直接写计划** | 跳过盘问；仍强制最小章节（目标 · 不做 · 验收）；缺口记为假设 |

### 1.2 主路径（≤5 步）

```text
选入口 → 答几题（或跳过）→ 看 Brief → 认领成计划 → 分配计划
```

分配之后进入既有拆分台 / 确认开跑；澄清相**不**改后半段。

### 1.3 认领与开跑

| 动作 | 结果 | 禁止 |
|------|------|------|
| **认领并写成计划** | session / plan 草稿落盘 | 调 `confirm_start`、spawn worker |
| **分配计划** | 进入拆分台 | 在聊天里直接开干 |
| **拆分台确认** | 唯一业务开跑 | 旁路第二闸门 |

## 2. 不做（与计划「不做」对齐）

| 不做 | 原因 |
|------|------|
| **非 vibe-check 全量** | 不移植 Crazy 8 HTML 引擎、ODI 全量打分、交互式 PRD 站、Checkup Mode、构建期 Git 教学 |
| **非 guided G0–G4 全量** | 全量引导 / 人生 OS / 多方内心剧场 / 主持人自动评分另轨；本子集不重开 |
| 云端用户画像 / 创业验证 SaaS | local-first；cco 仍是任务控制台 |
| 医疗 / 法律 / 投顾话术 | 硬边界 |
| 旁路 `confirm_start` | 开跑唯一闸在拆分台 |
| 聊天 spawn worker | 聊天只共建 plan |
| 改 Scheduler / 拆分图格式 / 第二套 Planner | 澄清态挂在 chat session meta，不是新编排机 |
| 默认联网挖论坛当证据 | 证据轻标签即可；外链由用户粘贴或后续可选增强 |

## 3. 与 PRODUCT ① 的关系

PRODUCT 主循环：

```text
① 生成计划 → ② 核对 → ③ 拆分 → ④ 并行 → ⑤ 巡检
```

| 关系 | 说明 |
|------|------|
| **澄清相 ⊆ ①** | 把「用自然语言 / 聊天写出要干什么」从空心出稿，收成「澄清 → 认领 → plan」 |
| **不改 ②–⑤** | 核对仍是人看计划；开跑仍拆分台确认；并行 / 巡检不变 |
| **文案衔接** | 澄清相主 CTA =「认领并写成计划」；全产品后半段仍用「分配计划」 |
| **计划一等公民** | Brief 是中间展示，不是 PlanIR；认领后才是可分配的 plan.md |

故事板仍是小陈那条：聊出计划 → 看全文改两句 → 分配 → 跑。澄清相只是让「聊出计划」前多一层真问题 / 范围 / 验收，避免空心。
