## 0. 一句话

把桌面端从「编排器调试面板」改成「项目任务控制台」：  
**少概念、浅色、大日志、一条主路径**——用户只关心「哪个项目 / 哪份计划 / 跑得怎样」。

> **产品决议**：默认模式为 **B（AI 规划拆分 + 定序 + 按图执行）**；**D1（2026-07-18）**：桌面默认 **分配后 auto-start**，高级「规划后暂停确认」。  
> 完整流程见 [`product-mode-b-ai-planner.md`](../product-mode-b-ai-planner.md) §4.1。本 UX 计划 0–4 是 **监视与壳底座**；业务 worker **只**经 `confirm_start`（默认 UI 自动调用），禁止旁路 spawn。

## 1. 背景与问题

### 1.1 产品用途（不变）

**cco** = 独立 CLI 编排器：指定项目目录 + 计划文档 → DAG 调度多个 agent CLI（首期 Claude）→ 巡查 / 停止 / 恢复。  
桌面 App 是本机监视与操作壳，不是业务仓库的一部分。

### 1.2 用户心智（设计锚点）

```text
1. 我要改哪个项目？
2. 我要 AI 按哪份计划干？
3. 现在跑得怎么样？出问题能不能看清、好处理？
```

## 2. 改版原则

1. **一条主路径**：添加项目 → 选/建计划 → 开始 → 看进度  
2. **默认值优先**：claude + 推荐模式；高级选项折叠  
3. **监视优先于配置**：运行中 ≥70% 纵向空间给输出  
4. **出问题能放大**：任务列表 + 主日志全宽可读  
5. **人话**：中文状态、失败一行摘要、少暴露 id  
6. **浅色桌面风**：白/浅灰，不是终端黑皮

## 3. 目标信息架构

```text
┌────────────┬──────────────────────────────────────────────┐
│ 我的项目    │  [项目名]                      [环境] [设置] │
│            │──────────────────────────────────────────────│
│ ○ AppA     │  未运行：步骤引导 + 计划列表 + [开始运行]      │
│ ● AppB     │  运行中：进度顶栏 + 左任务列表 + 右主日志       │
│ [＋ 添加]  │  完成/失败：摘要 + 再跑 / 继续                 │
└────────────┴──────────────────────────────────────────────┘
```

### 3.1 砍掉 / 降级

| 现状 | 目标 |
|------|------|
| 独立「总览」作主入口 | 侧栏项目带状态点；首页 = 当前项目或欢迎页 |
| 弹窗 Tab「新建运行」 | **删除**；只在项目内开始 |
| 计划 chips + 下拉双控件 | **单一计划列表** |
| Provider / Mode 常驻 | **高级选项**折叠 |
| 多列小 CLI 卡片墙 | **默认主从布局**（左任务 / 右大日志） |
| 预览 schema 工程字段 | 标题 + 任务数 + 步骤人话列表 |

### 3.2 保留（能力不丢）

- 多项目列表、默认/上次计划记忆  
- 启动 / 停止任务 / 全部停止 / resume  
- 环境检查（doctor）、设置（轮询等）  
- fake provider（放进高级：模拟运行）  
- 计划扫描与文件选择

## 4. 界面规格

### 4.1 视觉（浅色 · macOS 风）

| Token | 值 |
|-------|-----|
| 页面背景 | `#F5F5F7` |
| 侧栏 / 卡片 | `#FFFFFF` |
| 边框 | `#E5E5EA` |
| 主文字 | `#1D1D1F` |
| 次要文字 | `#6E6E73` |
| 主按钮 | `#0071E3` → 白字 |
| 成功 | `#34C759` |
| 警告 | `#FF9F0A` |
| 危险 | `#FF3B30` |
| 日志区背景 | `#FAFAFA` |
| 日志文字 | `#1D1D1F` |
| 日志字号 | **14px（0.875rem）**，行高 **1.5**；设置可调 12/14/16 |
| 圆角 | 10–12px |
| 字体 | SF Pro / system-ui；等宽 SF Mono / Menlo |

**禁止**：整页近黑底、正文日志 &lt; 13px、深色 badge 堆叠作为主状态表达。

### 4.2 冷启动 / 空状态

**无项目**

- 主区居中标题：用计划驱动多个 Claude 一起干活  
- 主按钮：**添加项目文件夹**  
- 次要：查看示例计划 / 帮助  

**有项目、无计划**

- 文案：此项目还没有计划  
- 计划 = 给 AI 的任务说明书  
- 按钮：**从模板创建** / **选择已有 .md**  

### 4.3 未运行 · 计划选择

- 列表项：计划标题（name 或文件名）+ `N 个任务 · 最多同时 M 个`  
- 路径仅小字或 hover  
- 选中后：步骤清单（title，非 raw 工程字段墙）  
- 主按钮唯一：**开始运行**  
- 高级 ▾：  
  - 模拟运行（fake，不调 API）  
  - 执行方式：前台运行（推荐）/ 后台 / 自动  

### 4.4 运行中 · 监视（核心）

**默认：主从（Master–Detail）**

| 区域 | 规格 |
|------|------|
| 顶栏 | 状态 · 进度 `已完成 a/b` · 用时 · [全部停止] [继续] |
| 左任务列表 | 宽 240–280px；状态点 + 名 + 用时；失败标红 + 一行摘要 |
| 右主日志 | 剩余全宽全高；≥14px；粘底滚动；复制 / 字号 /（可选）外置终端 |

**布局策略**

| 任务数 | 布局 |
|--------|------|
| 1 | 全宽日志（可隐藏左栏） |
| 2–3 | 主从；或可选 2 列但单卡高度 ≥ 480px、字号仍 ≥ 14px |
| ≥4 | **强制主从**，禁止邮票墙 |

**运行中计划区**：折叠为一行 `计划 xxx · 更换`，不占主高度。

### 4.5 日志可读性

| 项 | 现状 | 目标 |
|----|------|------|
| font-size | 0.72rem | **0.875rem（14px）** |
| 行高 | 1.4 | **1.5** |
| 可视高度 | 卡 max 420 | 主日志占满主区剩余 |
| log_max_bytes | 24KB | **96KB–128KB**；提供「完整日志」入口 |
| 错误展示 | 混在 tail | 列表/顶栏优先 `t.error`，否则 tail 末行 |
| 底栏 | bytes / session | 用时 / 成本；session 进详情 |

### 4.6 文案映射

| 系统 / 现状 | 界面 |
|-------------|------|
| 允许的项目 | 我的项目 |
| 启动并监视 | 开始运行 |
| running | 运行中 |
| failed | 失败 |
| paused | 已暂停 |
| completed / done | 已完成 |
| Provider | （高级）运行引擎 |
| Mode print | 前台运行 |
| Mode bg | 后台运行 |
| Mode auto | 自动选择 |
| run_id | 默认隐藏，详情可显 |
| 移出列表 | 从列表移除 |

### 4.7 环境门禁

- 首次进入或点「开始运行」前跑 doctor（可缓存）  
- 缺 CLI / 缺 key：主区警告条 + 重新检查，不丢长串 spawn 错误给新人

## 5. 目标用户流程

> 下列为 **模式 B 对齐后** 的主路径。旧版「预选计划 → 直接开始运行」已废弃为默认。

```text
打开 App
  ├─ 无项目 → 欢迎页 → 选文件夹 → 进入该项目
  └─ 有项目 → 恢复上次选中项目

项目页
  ├─ 选计划（默认/上次/列表）
  ├─ [分析并拆分任务] → 规划中（Planner AI / 日志）
  ├─ 待确认：波次 + 依赖 + 任务列表 → [开始运行]
  │     （高级：已是结构化计划可跳过规划）
  └─ 环境校验 → 执行监视布局

监视
  ├─ 左：全部分配 CLI（排队 / 运行中 / 已完成 / 失败）
  ├─ 右：当前任务大日志
  ├─ 失败 → 自动选中 + 顶栏错误
  ├─ 全部完成 → 成功摘要 + 再跑 / 换计划
  └─ paused/failed → 「继续未完成任务」
```

细节与阶段 B0–B3：[`product-mode-b-ai-planner.md`](../product-mode-b-ai-planner.md)。

## 9. 推荐实施顺序

```text
阶段 0（止血） → 阶段 1（主从日志） → 阶段 2（主路径） → 阶段 3（打磨） → 阶段 4（文档）
```
