# 计划 01 · 主受众与职业场景

> 本波：[INDEX.md](./INDEX.md) · 落地：[landing.md](./landing.md)  
> 问题：cco **为谁**做主路径文案与默认体验？  
> 状态：决策向 · 实施随 W0 模板/例子 ☐

---

## 目标

冻结**主受众扩表**：创业者、小老板、产品经理、设计师/UI、运营/出海、新媒体与自媒体、电商卖家、教师/培训、企业行政/财务/HR 等非开发业务方；开发者为次受众。  
可观察结果：改空态例子、模板、失败文案时有表可查；不按职业锁死功能。

## 非目标

- 为每个职业做独立 App 模式  
- 开发者主路径抢戏  
- 用问卷收集「你是什么职业」当大门  

## 主受众表

| 角色 | 典型要推的事 | 常处深度 | 要什么 | 不要什么 |
|------|--------------|----------|--------|----------|
| 创业者 / 小老板 | MVP、官网、报价、内部小工具 | L→M，偶 H | 快验、人话、少设置 | 术语、长问卷、像 IDE |
| 产品经理 | PRD→可执行；多需求包 | M / H | 计划可读可改；多文档关系；对照验收 | provider、schema |
| 设计师 / UI | 落地页、说明→可点预览 | L / M | 结果看得见 | 终端日志墙 |
| 运营 / 增长 / 出海 | 多语言、活动、表单线索 | M，大促 H | 多线人话进度 | 装开发环境 |
| 新媒体 / 自媒体 / 内容 | 栏目、铅封、内容站 | L / M | 模板快起；边聊选题 | 工程黑话 |
| 电商卖家 | 详情页、活动页、小工具 | L / M | 快上线；验收=像不像 | 复杂依赖表 |
| 教师 / 培训 | 课件站、报名、练习说明 | L / M | 结构清、可发给学员 | 技术配置 |
| 行政 / 财务 / HR | 制度、收集表、内宣 | L / M | 稳、可存档、失败人话 | 调试面板 |
| 业务负责人（非开发） | 用 AI 推业务 | M | 像管项目 | 英文堆栈 |

**次受众**：开发者、CLI/TUI/自动化——能力进高级。

## 心智三问（改界面先过）

```text
1. 我要推哪个项目？
2. 计划写清楚了吗？（多计划时：索引与关系对不对？）
3. 现在跑得怎样？做完了吗？
```

## 职业 × 路径默认（仅推荐，不锁死）

| 更常默认 | 例 |
|----------|-----|
| L 快试 | 电商试活动页、自媒体试铅封、周末验证 |
| M 一份计划 | 单需求 PM、单页制度、一屏设计交付 |
| H 多需求 | PM 需求包、大促多页、出海多语言多线 |

## 对产品的增益

- 文案/模板/空态例子有对象，减少「为开发者写的控制台」漂移  
- 与 [02](./02-iterate-clarity.md) 的「想不清」叠加：主用户**大多**不会一次写对  
- 与 [03](./03-path-empty-cta.md) 的 L/M/H：用职业只影响**推荐与例子**，不复制三套业务
