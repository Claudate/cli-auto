# 计划 01 · 主受众与职业场景

> 本波：[INDEX.md](./INDEX.md) · 落地：[landing.md](./landing.md)  
> 问题：cco **为谁**做主路径文案与默认体验？  
> 状态：决策向 · 实施随 W0 模板/例子 ☐

---

## 目标

冻结**主受众扩表**：创业者、小老板、产品经理、设计师/UI、运营/出海、新媒体与自媒体、电商卖家、教师/培训、企业行政/财务/HR 等非开发业务方；开发者为次受众。  
可观察结果：改空态例子、模板、失败文案时有表可查；不按职业锁死功能。

## 非目标

- 为每个职业做独立 App 模式  
- 开发者主路径抢戏  
- 用问卷收集「你是什么职业」当大门  

## 主受众表

| 角色 | 典型要推的事 | 常见做法（人话） | 要什么 | 不要什么 |
|------|--------------|----------|--------|----------|
| 创业者 / 小老板 | MVP、官网、报价、内部小工具 | 先能看再写全 | 快验、人话、少设置 | 术语、长问卷、像 IDE |
| 产品经理 | PRD→可执行；多需求包 | 一份计划或本波多份 | 计划可读可改；多文档关系；对照验收 | provider、schema |
| 设计师 / UI | 落地页、说明→可点预览 | 一屏草稿或完整一页 | 结果看得见 | 终端日志墙 |
| 运营 / 增长 / 出海 | 多语言、活动、表单线索 | 单页或大促多页本波 | 多线人话进度 | 装开发环境 |
| 新媒体 / 自媒体 / 内容 | 栏目、铅封、内容站 | 先发链接再系列 | 模板快起；边聊选题 | 工程黑话 |
| 电商卖家 | 详情页、活动页、小工具 | 单品上架；多品分开 | 快上线；验收=像不像 | 复杂依赖表 |
| 教师 / 培训 | 课件站、报名、练习说明 | 单课说明为主 | 结构清、可发给学员 | 技术配置 |
| 行政 / 财务 / HR | 制度、收集表、内宣 | 单份正式稿+确认 | 稳、可存档、失败人话 | 调试面板 |
| 业务负责人（非开发） | 用 AI 推业务 | 可汇报的一份或本波 | 像管项目 | 英文堆栈 |

**次受众**：开发者、CLI/TUI/自动化——能力进高级。

## 心智三问（改界面先过）

```text
1. 我要推哪个项目？
2. 计划写清楚了吗？（多计划时：索引与关系对不对？）
3. 现在跑得怎样？做完了吗？
```

## 职业 × 路径：错误示范 vs 正确做法

### 错误（已废弃）

| 更常默认 | 例 |
|----------|-----|
| L | 电商、自媒体、周末… |
| M | PM、制度、设计… |
| H | 需求包、大促… |

→ **只把人贴到三个字母上**，开场/按钮/验收/确认严格度全一样 = **没有按用户优化**。

### 正确

**按用户优化** = [01b](./01b-persona-path-profiles.md) 多维旋钮 + 场景芯片（用户可感）。  
**交付形态** trial/single/bundle（旧 L/M/H）= **仅引擎内部**，由芯片/话术/附件推断；**空态不教三档**（见 [03](./03-path-empty-cta.md)）。

| 画像 | 内部形态偏向 | 用户可感优化（一眼） |
|------|--------------|----------------------|
| 小老板 | trial 偏 | 生成并看看 · 砍支付 · 演示验收 |
| PM | single；材料多→bundle | 禁直接执行 · 细拆 · 清单 · 本波目录 |
| 设计 | single | 第一眼/主钮 · 可预览 · 走查 |
| 运营出海 | bundle 偏 | 战役目录 · 多页并行 · 表收语齐 |
| 内容 | trial 偏 | 发链接 · 语气 |
| 电商 | single；多品 bundle | **上架清单** · 禁编造 |
| 教培 | single | 学员路径 · 稳 |
| 行政HR | single | **严格确认** · 必审句 |
| 业务负责人 | single/bundle | 可汇报 · 管事 |

场景芯片套画像；**不**进门选职业；**不**进门选 L/M/H。
