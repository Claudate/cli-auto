## 0. 校正：为什么「三档表」必须优化掉

| 旧设计（废弃作主路径） | 问题 |
|------------------------|------|
| 空态先选 L/M/H | 又一套分类考试；非技术不懂、也不该懂 |
| 「与澄清正交，先选档再问」 | 两套入口叠床架屋 |
| 顶栏随 L/M/H 变步骤名 | 用户被训练记产品黑话 |
| 文档大表教三档含义 | 和「更智能、更懂用户」相反——**智能应是系统猜对形态** |

**用户要的**：打开就说事 / 点一个像自己业务的例子 → AI **更懂**要试一把还是要一整份还是要一包。  
**不是**：先学会三种工作方式。

```text
废弃（主路径）：选档 → 输入 → …
目标（主路径）：输入（或点场景）→ 系统推断交付形态 → 唯一下一步
高级（可折）：「只要一句话试试」「我有很多份材料要一起排」——人话，不叫 L/H
```

## 1. 目标

1. **空态**：主输入视觉第一；**无** L/M/H 三键英雄区。  
2. **场景芯片 / 画像（01b）**：唯一推荐的「弱分群」入口（可跳过）。  
3. **交付形态自动/软推断**（对内 trial/single/bundle）；用户可一句人话纠正，不学代号。  
4. **草稿卡**：唯一主 CTA；禁双卡同文；直接执行降权。  
5. 问卷/澄清：**永不**当大门；深度跟画像与对话，不跟「用户选的档」。

可观察：10 秒找到输入；不问「三个档位啥意思」；多材料时系统自己建议「先做个目录」而不是逼选「多需求档」。

## 3. 对内：交付形态（旧 L/M/H 更名，勿上 UI）

| 对内 ID | 迁移期别名（禁 UI） | 引擎含义 | 用户如何触发（人话/芯片） |
|---------|------|----------|------------------------|
| `trial` | 曾称 L | 短计划或单任务；少问；可谨慎直接跑 | 场景「验证想法」；话里「先看看/试一下」；极短一句 |
| `single` | 曾称 M | 一份 plan.md → 拆 → 确认 → 跑 → 验 | **默认**；场景写需求/上架/开课/发文等 |
| `bundle` | 曾称 H | 索引 + 多 plan（04+） | 多附件；场景「大促多页」；话里「好几件事/多页一起」 |

**推断优先级（高覆盖低）**：

```text
1. 用户人话明确（「只要试试」「多页一起排」）
2. 场景芯片 / 01b `delivery_bias`（内部）
3. 信号：附件≥2、列表枚举多项交付 → 倾向 bundle
4. 全局默认 single
```

**禁止**：空态三个大按钮绑定 trial/single/bundle 并要求先点。  
**允许**：高级折叠「更多」里人话两项纠正；或 AI 一句确认「你是想先看一版，还是把这几页排成一波？」——仍 ≤1 问、非三档课。

## 4. 空态结构（目标态 · 取代三键）

```text
┌─────────────────────────────────────────────┐
│  （项目名）                                   │
│  ┌ 主输入（最大 · 永远第一）                 │
│  │ 占位随场景变：说要做成什么，或拖入材料…   │
│  └──────────────────────────────────────────┘
│  可点例子（芯片·可跳过）：                     │
│  验证想法 · 写清一件事 · 大促多页 · 上架 · …  │
│  次要：模板 · 接上上次 · 需要时再问一两句     │
│  （无「快试|一份计划|多需求」三英雄键）        │
└─────────────────────────────────────────────┘
```

同屏概念 ≤3：**输入 ·（可选）例子 · 下一步**。  
点芯片 → 只套用 [01b](./01b-persona-path-profiles.md)（opener/cta/direct/验收词 + **内部** `delivery_bias`）。  
**不**再渲染 pathMode 三段控件为默认可见。

## 5. 草稿卡（保持，不绑三档文案）

- 一卡一份计划；禁双卡同文  
- 三行人话：做成什么 / 不做 / 怎样算完  
- **一个**主 CTA：文案跟 **01b primary_cta**（生成并看看 / 拆成步骤 / 生成本波目录…），**不是**跟用户选的三档  
- 直接执行：仅 trial 信号或画像 `direct_exec=offer` 时弱入口；默认 ghost/⋯  
- 反馈：按我说的改 / 这版去拆步（02）

## 6. 顶栏

| 阶段 | 人话（固定骨架） |
