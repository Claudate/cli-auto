# UI 风格路由 — 从用户需求快速定位样式（web / app 通用）

> 注入点：聊天 + 拆分 Agent 追加，位于 `ui-premium-styles.md` **之前**读取。
> 作用：用户一句模糊描述（"做个官网""帮我做个 app 首页""要高级感"）→ 三步内定下 品类 → 配方（A–E）→ 载体形态（web/app），不追问、不空转。

## 第一步：品类判定（从用户词语直接映射，命中即用）

| 用户说 | 品类 | 配方 | 布局真源 |
|---|---|---|---|
| 官网 / 落地页 / landing / 宣传页 / SaaS / 工具 / AI 产品 | marketing | **A 极简亮色** | marketing-landing-reference SPEC |
| agency / 工作室 / 摄影 / 作品集 / 奢侈 / 高端 | portfolio | **B 暗色奢华** | portfolio shell |
| 民宿 / 咖啡 / 生活方式 / 品牌 / 亲子 / 餐饮 | lifestyle | **C 温暖有机** | marketing SPEC |
| 活动 / 演出 / 潮流 / 发布会 / 体育 | event | **D 粗犷海报** | marketing SPEC |
| 产品发布 / 硬件 / 汽车 / 影视 | launch | **E 电影感视频** | marketing SPEC |
| 后台 / dashboard / 管理系统 / admin | app-tool | A（+密集表格/侧栏导航） | app-shell-lite |
| 小程序 / 手机 app / 移动端界面 | mobile-app | 见下方「App 载体规则」 | — |

未命中时按受众反推：B 端企业客户→A；C 端年轻消费者→C/D；品牌溢价→B；演示冲击力→E。

## 第二步：用户「口味词」修正（叠加在配方上，不是换配方）

- 「高级感 / 质感 / 轻奢」→ 对应配方的签名效果必选**衬线斜体 display**（A 配方也临时换 display 为 Instrument Serif italic）
- 「简约 / 干净 / 性冷淡」→ 删签名效果，只留分节交替 + hover 微交互；色收敛到单色 CTA
- 「活泼 / 年轻 / 潮」→ 圆角加大一档、强调色饱和度 +100、可加 marquee；仍禁彩虹渐变
- 「专业 / 可信 / 企业」→ 蓝系主色、加 logo 墙与合规徽标位、动效降为只保留 reveal
- 「国内 / 出海」→ 国内：微信/支付宝图标、备案位、中文排版（`PingFang SC` 栈、正文 ≥15px、行高 1.8）；出海：英文优先、可加 testimonials/press 墙
- 「快 / 先看效果」→ 直接抄 `examples/site-floor/RECIPE-MAP.md` 的 R-* 组合，不重新设计

## 第三步：App 载体规则（mobile app / 小程序，与 web 的差异点）

- **导航**：底部 tab（3–5 个）为默认；二级页左上返回；禁止 web 式顶部多级导航
- **触控**：可点目标 ≥44×44pt；主操作右下/底部固定；表单单列
- **安全区**：`safe-area-inset` 顶部底部都要留；列表底部留 tab 高度
- **字体/色彩**：沿用所选配方的字体对与色板，但字号整体 −1 档、对比度再提高（户外可读）
- **状态**：加载（骨架屏）、空态（插画+一句人话+CTA）、错误（可重试）、断网，四态必做
- **动效**：只用 micro 档（0.12–0.2s）+ 页面转场；web 的 parallax/pin 不进 app

## 输出格式（写计划 / 拆分时必须先落这三行）

```text
风格定位：品类=<品类> · 配方=<A–E 或 app-tool> · 载体=<web|mobile-app>
口味修正：<命中的修正词，无则写 无>
签名时刻：<该页唯一的标志性效果名>
```

三行落定后再写布局/区块（`ui-layout-systems.md`）与色/字 kit；后续所有页面共享同一定位，不中途换风格。

## 红线

- 用户没给口味词时**不追问样式**，按品类默认直接做，做完在聊天里说「我按 X 配方做了，想换风格回我一句」
- 同一项目内配方不混用；app 载体不得套用 web 的整屏视频/parallax
- 修正词只能改当前配方的参数（圆角/饱和度/display 字体），不能引入新色相
